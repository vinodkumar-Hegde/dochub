# DocHub Premium V10

Based on the V9 prototype. Changes: fixed shared collapsible sidebar alignment/labels, neutral compact navigation, removed Student Settings and font preference entry, persistent thumbnail rail in PDF zoom and Fit Page modes, Pen/Highlighter/Eraser toolbar, and only Read/Plan to Read choices on thumbnails.

**Limitations:** PDF pages, thumbnails and annotation strokes are illustrative simulations. Cross-browser testing and accessibility audits have not yet been completed. Real PDF rendering and durable annotation storage remain future integration work.

Run from extracted project folder: `npm install && npm run dev` on port 5180.
