# DocHub V7 — Minimal clickable UI

Changes to student learning: each material row opens its reader directly (keyboard accessible); no Open buttons; compact programme and subject chips; neutral icon surfaces and sidebar. All other workflows inherited from V6.

Run `npm install` then `npm run dev -- --host 127.0.0.1 --port 5177 --strictPort`. Open http://127.0.0.1:5177 . Look for V7 MINIMAL in the header.

Prototype PDF display remains simulated. Full browser regression tests have not been run.
