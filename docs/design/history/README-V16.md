# DocHub V16 – branding and white UI

- Consistent white application surfaces.
- Supplied DocTutorials logo is used in sidebar branding and as browser favicon.
- Guided empty learning state prompts the student to select a programme/subject.
- Notification rows use contextual icons for session, document and other updates.
- All other V15 behavior retained, including the desktop session table and mobile tiles.
