# DocHub V9 — collapsible navigation and student materials views

- Desktop sidebar toggle switches between labeled menu and icon-only rail. Icon buttons retain accessible labels and tooltips, across all roles.
- On mobile, navigation remains an overlay for accessibility.
- Student materials support Detailed list and Gallery views; clicking any row/card directly opens the reader.
- Existing mock access control and reading progress remain unchanged.
- This release still uses simulated PDF pages.

Run: `npm install && npm run dev -- --port 5179 --strictPort`
